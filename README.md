# Бар «Ещё по одной»

Виртуальный 3D-бар на восьмерых: один стол, ссылка с ключом, голос и чат.

Сайт: https://dartanyun.github.io/bar/

- Столы по ключу: ссылка вида `…/bar/#stol-xxxxx` ведёт всех за один стол.
- Голос и данные идут напрямую между браузерами (WebRTC, PeerJS).
- Музыкальный автомат, дартс, бутылочка, тосты, шкала «градуса».

Весь сайт — один файл `index.html`, сборка не нужна.
